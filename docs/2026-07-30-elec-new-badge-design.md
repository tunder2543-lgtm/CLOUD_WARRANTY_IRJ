# ป้าย "New +N" แจ้งไฟล์ใหม่ที่ยังไม่ได้ดู (คลัง Live FB/TikTok/Sell)

วันที่: 2026-07-30

## เป้าหมาย
เมื่อมีไฟล์ใหม่เข้ามาในคลัง (จากระบบภายนอกที่อัปขึ้น bucket) และผู้ใช้ยังไม่ได้เข้าไปดู
ให้แสดงป้ายสีแดง **`New +จำนวน`** ข้างชื่อหัวข้อในเมนูซ้าย เพื่อเตือนว่ามีของใหม่กี่รูป

## การตัดสินใจหลัก (ผู้ใช้ยืนยันแล้ว)
1. **"ใหม่" นับทั้งกลุ่มใหม่ + ไฟล์ใหม่ในกลุ่มเดิม** — หน่วยเป็น "จำนวนไฟล์"
2. **เก็บสถานะ "ดูแล้ว" ใน localStorage ต่อเบราว์เซอร์** (ไม่แตะ DB/policy)
3. **แสดงป้ายที่เมนูซ้ายเท่านั้น** (ข้าง Live FB/TikTok/Sell)
4. **ล้างป้ายเมื่อเปิดเข้าหัวข้อนั้น**

## Data model (localStorage)
- คีย์: `laser_dash_v3_elec_seen`
- ค่า: `{ "<bucket>": { "<folder>": <จำนวนไฟล์ที่ดูแล้ว> } }`
  เช่น `{ "live-fb": {"2026-07-23":54,"grp_x":33}, "live-sell": {"2026-07-30":2} }`

## การคำนวณ
- ระหว่าง list bucket (prefetch ตอนเปิดแอป / โหลดหน้าหัวข้อ / กดรีเฟรช) เก็บ **จำนวนไฟล์ปัจจุบันต่อโฟลเดอร์**
  ลง `elecFolderCountCache[bucket] = {folder:count}`
- **New ต่อหัวข้อ** = ผลรวมของ `max(0, จำนวนปัจจุบัน − จำนวนที่ดูแล้ว)` ทุกโฟลเดอร์
  - โฟลเดอร์ใหม่ (ไม่มีใน seen) → นับทุกไฟล์เป็นใหม่
  - โฟลเดอร์เดิมที่ไฟล์เพิ่ม → นับเฉพาะส่วนต่าง
- ถ้า `New > 0` → แสดง `<span class="sb-new">New +N</span>` ในเมนูซ้าย

## พฤติกรรม
- **ครั้งแรกสุด (ยังไม่มีคีย์ seen เลย):** ตั้งต้น seen = จำนวนปัจจุบันของทุก bucket (หลัง prefetch)
  → ไม่ขึ้น New ค้างตั้งแต่วันแรก จะขึ้นเฉพาะของที่เข้ามาหลังจากนี้
- **เปิดเข้าหัวข้อ (โหลดสำเร็จ):** บันทึกจำนวนไฟล์ปัจจุบันของหัวข้อนั้นเป็น seen → ป้าย New หาย
- **อัปเดตเมื่อ:** เปิดแอป (prefetch) และกด "🔄 รีเฟรชจากคลัง" — ไม่ใช่ real-time push
  (ถ้าต้องการเด้งสดต้องใช้ Supabase Realtime เพิ่มภายหลัง)

## หน่วยที่แก้

  `elecLoadSeen/elecSaveSeen/elecNewCount/elecMarkSeen/elecSeedSeenIfEmpty`;
  เก็บ per-folder count ใน `loadElecGroups` และ `prefetchElecCounts` (+ seed + mark seen ตอนเปิดหัวข้อ)
- **js/app.js**: `sbItem()` เพิ่มป้าย `New +N` สำหรับหัวข้อ elec
- **css/layout.css**: สไตล์ `.sb-new` (พิลล์แดง)
- **index.html**: bump `?v=28` → `?v=29`
